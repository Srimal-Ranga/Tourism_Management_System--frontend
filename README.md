# Tourism_Management_System--frontend

🚀 How To Run Your Friend’s Next.js Project

When your friend sends a Next.js project, it does NOT include installed files.

So you must prepare it on your computer.

📦 Step 1 — Install Project Files

Open terminal inside the project folder and run:

npm install


✨ What this does:

Reads package.json

Downloads Next.js, React, and other libraries

Creates node_modules folder

Prepares the project to run

⏳ Wait until it finishes.

▶ Step 2 — Start the Project

After installation:

npm run dev


✨ What this does:

Starts Next.js development server

Compiles your project

Creates a local website

You will see:

http://localhost:3000

🌐 Step 3 — Open in Browser

Open your browser and go to:

http://localhost:3000


🎉 Your Next.js project is now running!
